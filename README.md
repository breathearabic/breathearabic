# Arabic Vocabulary web app

This folder is the whole website. Upload it to Netlify as-is (drag the folder onto **Deploys**).

- `config.js` is the only file you edit. It holds your Supabase address and public key, and the Subscribe switch.
- `admin.html` is your admin page.
- `privacy.html` and `terms.html` are drafts to review before launch.

Full setup steps are in `SETUP.md`, one folder up. Never put a secret key in any file in this folder.
